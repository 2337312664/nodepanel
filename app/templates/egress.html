中转 / 落地

出网走向的两个可叠加功能：用户的连接方式和订阅链接始终不变，改完保存即生效。 叠加时流量走 用户 → 本机 → 落地机 → 住宅代理 → 目标。

{# 出口一：住宅代理落地。关闭时下面的字段会连同凭据一起清空。 #}

把本机的出网流量交给住宅代理，网站看到的是代理的 IP。 用户的连接方式和订阅链接完全不用改。

{% if relay_active and settings.relay_ok == '0' %}

⚠️ 上次保存时无法连上 {{ settings.relay_server }}:{{ settings.relay_port }}。 配置已生效，但请确认地址端口正确、代理允许你服务器的 IP 接入。

{% endif %}
代理地址不能填内网或环回地址。UDP 走代理需要代理支持 UDP ASSOCIATE，多数住宅代理不支持； 关闭时面板会拦掉 UDP 流量，避免它绕过代理直连暴露真实 IP。 开启「弱网连接(Hysteria2)」且这里选「否」时，Hysteria2 会连不通——它必须走 UDP。
{# 出口二：中转落地。入口机填这里，参数来自落地机的「导出接入参数」。 #}

把流量推给另一台落地机（那台也装了本面板），由它出网，本机 IP 不会暴露给目标。 在落地机上用「导出接入参数」拿到下面这组值，原样填进来即可。 用户的连接方式和订阅链接完全不用改。

{% if uplink_active and settings.uplink_ok == '0' %}

⚠️ 上次保存时无法连上 {{ settings.uplink_server }}:{{ settings.uplink_port }}。 请确认地址端口、落地机防火墙和云安全组都已放行。

{% endif %}
入口机和落地机在同一内网/机房专网时，选「允许内网地址」才能填内网 IP；环回地址始终不允许。 只用这一项时 UDP 不会经过落地机（VLESS 走 TCP），要放行 UDP 请用 Hysteria2。 与上面的「住宅代理落地」可以叠加，叠加时流量走 用户 → 本机 → 落地机 → 住宅代理 → 目标。
